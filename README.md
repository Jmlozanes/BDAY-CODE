# 🎂 Birthday Surprise Website

A special interactive birthday website created using **HTML, CSS, and JavaScript**.

This project is a personalized digital birthday surprise featuring animations, a passcode lock, interactive transitions, background effects, and a final birthday greeting page with music.

---

## ✨ Project Overview

The website guides the user through a birthday experience:

1. 🎉 Birthday Loading Screen
2. 🔐 Birthday Passcode Lock
3. ✨ Magic Birthday Portal
4. 🎂 Final Birthday Celebration Page

Each page provides a different interactive experience using custom animations and JavaScript functionality.

---

## 🚀 Features

### 🎈 Birthday Loading Screen
- Animated loading progress bar
- Floating birthday decorations
- Countdown animation
- Custom birthday-themed design

Files:
- `index.html`
- `style.css`
- `script.js`

---

### 🔐 Birthday Passcode System
A birthday date-based lock screen that allows access to the surprise.

Features:
- Custom passcode input interface
- Animated phone-style design
- Passcode validation using JavaScript
- Success and error messages

Files:
- `Passcode.html`
- `Passcode.css`
- `Passcode.js`

---

### ✨ Magic Birthday Portal
An interactive transition page that opens the birthday surprise.

Features:
- Animated portal effect
- Floating stars and decorations
- Interactive button effects

Files:
- `present.html`
- `present.css`
- `present.js`

---

### 🎂 Final Birthday Celebration
The final surprise page containing the birthday message.

Features:
- Background music
- Animated birthday card
- Floating messages
- Sparkle effects
- Interactive animations

Files:
- `final.html`
- `final.css`
- `final.js`
